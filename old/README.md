# Archived website files

This directory preserves files that are not used by the current React website.

- `legacy-site/` contains the former GitHub Pages site, its assets, redirect files, and tests. Any local edits that existed before the redesign migration were preserved in their moved files.
- `experiments/` contains earlier redesign work.
- `misc/` contains standalone OCR and QR-code files that are not referenced by the current site.

These files are retained for reference and are not included in the production build.
